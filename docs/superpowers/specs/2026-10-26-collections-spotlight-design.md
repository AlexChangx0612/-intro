# 首頁「產品系列」標題區改版：新品聚光燈（B1）

日期：2026-10-26

## 目的與原因

首頁「產品系列」標題區目前只有標題、一行說明與電子目錄連結，畫面單調。網站的目標是讓客戶被實際案例與內容吸引，進而加入官方 LINE，由專員在 LINE 報價完成轉換。這個區塊要同時做到三件事：

1. 讓客戶清楚知道「下方就是產品系列」。
2. 畫面不單調，有會動、可互動的內容。
3. 展示新品上市消息（目前是 RS-258WE），並帶到服務與 LINE 報價。

## 目標／非目標／反目標

- 目標：左標題＋系列入口、右分頁式輪播（新品上市／免費規劃／LINE 報價）；新品卡片可點色票、織帶顏色跟著變；新品點下去到產品頁。
- 目標：替 RS-258WE 建立產品頁（目前不在網站目錄），讓新品卡片有地方可連。
- 目標：以後新品上市，只要改一個資料檔就能換卡片。
- 非目標：預備中的第二款新品（使用者決定先不處理）。
- 非目標：改動下方產品目錄、案例輪播或其他首頁區塊。
- 反目標：首屏磚牆已經在動，這裡不能變成第三個「一直捲動」的區塊；輪播要能暫停、能手動點分頁。
- 反目標：圖片不能糊（使用者很在意清晰度）。

## 方案（已選定 B1）

| 方案 | 說明 | 取捨 |
|---|---|---|
| A 亮點跑馬燈 | 一排膠囊標籤捲動 | 最輕，但新品沒有圖，與首屏同為捲動效果 |
| B 左標題右輪播 | 右側 3 張卡片自動輪播 | 新品有圖、系列入口清楚 |
| C 滿版大橫幅 | 整排大圖輪播 | 最搶眼，但現有圖太小會糊，且把系列推遠 |
| B1 新品聚光燈 ✅ | B 加上「看得到的分頁」與可互動色票 | 客人一眼知道有哪些內容、可自己點；新品話題性最強 |
| B2 卡片軌道＋13 系列圖示帶 | 移動卡片＋13 圖示 | 內容最多，但動態較多 |
| B3 拼貼牆 | 三格同時呈現，不輪播 | 最沉穩，但新品沒有互動亮點 |

使用者先選 B，請我以 B 延伸，再從 B1／B2／B3 中選定 **B1**。

## 已確定的內容（依示意稿 collections-header-b.html 的 B1）

**左側**
- 小標 COLLECTIONS、標題「產品系列」、說明「13 大系列，全系列台灣製造。選擇系列瀏覽，或往下看完整目錄。」（系列數由程式計算，不寫死）
- 系列小圖示標籤（分類去背圖＋名稱）：伸縮帶欄柱、迎賓欄柱、展覽佈展欄柱、拒馬、海報架・告示牌，點了以既有的 `#c-<分類 id>` 錨點切換並捲到下方商品。
- 最後一顆「全部 13 系列 ↓」捲到下方商品目錄。
- 保留「瀏覽產品電子目錄 →」連結。

**右側：分頁式輪播（3 頁）**
1. 新品上市：白底產品照（圖片2）＋「NEW 新品上市」標籤＋「RS-258WE 全白烤漆伸縮帶欄柱」＋5 色馬卡龍色票（櫻花紫 MP、檸檬黃 MY、米白 MW、湖水藍 MB、莓果粉 MR），點色票時產品照上的織帶換色並顯示色名；「查看新品介紹 →」連到 RS-258WE 產品頁。
2. 免費規劃：「免費空間動線規劃」＋說明＋「了解規劃服務 →」。
3. LINE 報價：LINE 綠底、「看到喜歡的款式？加 LINE 一對一報價」＋「加入好友」按鈕，連到 `site.line`。

- 下方三個分頁標籤（新品上市／免費規劃／LINE 報價），紅色進度線跑完約 6 秒自動換下一頁，可手動點選。
- 滑鼠移入或鍵盤聚焦時暫停；使用者系統設定「減少動態效果」時不自動輪播。

**RS-258WE 產品頁**
- 產品照放入 `public/images`，登錄 `product-models.ts`（型號、規格）與 `product-details.ts`（名稱、說明、規格、特色），歸入伸縮帶欄柱的萬向系列。
- 內容只寫圖片上看得到的事實：萬向系列、織帶長 200cm、全白烤漆柱身、可選購 5 色馬卡龍織帶、可升級彩色印刷織帶、Made in Taiwan。色票說明圖（圖片3）放在產品頁當第二張圖。

## 我做的判斷（請確認）

- 「了解規劃服務 →」連到 `/custom`（該頁已有「專人規劃、免費報價」說明）。
- 輪播內容放在新的資料檔（例如 `app/lib/spotlight.ts`），日後新增新品只改這個檔。
- 手機版：左右改為上下排列，標題在上、輪播在下；系列標籤改成可左右滑動的一排。
- 織帶換色用色塊疊在產品照的織帶位置上；因原圖只有 608px 寬，產品照顯示高度控制在約 240px 內，確保清晰。
- 色票顏色值是依圖片3目測取色，需要時可換成官方色號。
