# 客戶實際案例（真實照片＋案例詳細頁）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 9 個真實客戶案例取代 6 張示意圖，新增 `/cases/<slug>` 案例詳細頁（A＋C 合併版），並讓總覽頁與首頁輪播連到詳細頁。

**Architecture:** 照片由一支一次性的 sharp 腳本從原始資料夾壓縮進 `public/cases/<slug>/`。所有案例內容集中在 `app/lib/cases.ts`（扁平、純資料，方便日後搬進 CMS）。新增靜態路由 `app/cases/[slug]/page.tsx`，總覽頁、首頁輪播、關於／優勢頁的延伸閱讀卡片都只讀 `cases.ts`。

**Tech Stack:** Next.js 16（App Router，`PageProps<"/cases/[slug]">`、`generateStaticParams`、`dynamicParams = false`）、React 19、Tailwind v4、sharp（已在 node_modules）、tsx（`npx tsx` 可用）。

**Spec:** `docs/superpowers/specs/2026-10-24-cases-design.md`

## Global Constraints

- 原始照片：`C:/Users/user/Desktop/世紘興業實拍案例_原始圖片`（不可修改原始檔）。
- 排除 `17_出貨連江縣政府馬祖梅石藝文中心實際相片/01_image55.png`（手寫出貨單）。
- 壓縮：EXIF 轉正、長邊最大 1920px、JPEG quality 80、移除 metadata（sharp 預設不寫入 metadata，勿呼叫 `withMetadata`）。檔名 `01.jpg`、`02.jpg`…
- 9 個案例的 slug、標題、場域、來源資料夾與顯示順序，完全依 spec「案例與資料夾對照」表。
- `/cases` 與 `/cases/<slug>` 一律 `robots: { index: false, follow: true }`；`app/sitemap.ts` 不改。
- 文字不寫數量、日期、金額、客戶評語；不出現 01、02 這類序號。
- 沿用設計語言：`container`、`pageTop`、`section`、`card`、`cardHover`、`outlineBtn`、`bodyText`（`app/lib/ui.ts`），品牌紅標題、英文小標 `text-xs tracking-[0.35em] text-brand-deep`、18px 圓角。
- 每個程式檔沿用專案的逐行中文註解風格。

## Review Focus

- 直式手機照片（例如 1108×1477、960×1706）放進 16:9 或 4:3 框：必須 `object-cover` 且封面挑橫式或主體置中的照片，不可變形。→ Task 1 腳本輸出每張寬高，Task 2 驗證腳本檢查封面為橫式或正方形。
- 照片數很少的案例（台南天壇 3 張、台鋼雄鷹 4 張）：故事三段用掉 3 張後照片牆可能為空 → 照片牆區塊需在 `gallery.length === 0` 時整段不渲染。→ Task 3 驗證。
- 不存在的 slug（`/cases/abc`）：回 404。→ Task 3 驗證。
- 首頁輪播的複製卡片（`dup`）不可重複被讀屏軟體與 Tab 鍵讀到：連結在 dup 卡片上要 `tabIndex={-1}` 與 `aria-hidden`。→ Task 4 驗證。
- 刪除舊 `case-0x.jpg` 後全站無破圖：`grep -rn "cases/case-0" app` 必須為空。→ Task 5 驗證。

### Task 2: 案例資料 `app/lib/cases.ts`

**Files:**
- Modify: `app/lib/cases.ts`（整檔改寫）
- Create: `scripts/check-cases.mts`

**Interfaces:**
- Produces:

```ts
export type CasePhoto = { src: string; alt: string };
export type CaseStory = { en: string; title: string; body: string; photo: CasePhoto };
export type CaseStudy = {
  slug: string; title: string; scene: string; client: string; location: string;
  products: string; custom: string; summary: string;
  cover: CasePhoto; story: [CaseStory, CaseStory, CaseStory]; gallery: CasePhoto[];
  related: string[]; // 產品分類 slug，例如 "barriers"

export function caseHref(slug: string): string; // `/cases/${slug}`
```

故事三段固定為：`{ en: "NEEDS", title: "需求" }`、`{ en: "SOLUTION", title: "世紘的做法" }`、`{ en: "MADE IN TAIWAN", title: "製作與出貨" }`。

  - 同一案例內同一張照片不重複出現；每張 `public/cases/<slug>/*.jpg` 至少被用到一次。
  - `cover` 照片寬 ≥ 高（用 sharp 讀 metadata）。
  - 每個 `related` 都是 `getCatalog().categories` 中存在的 slug。
  - 所有文字欄位不符合 `/^\s*0?\d[.、・]/`（序號開頭），且不符合 `/\d+\s*(年|月|件|萬|元)/`（日期、數量、金額；型號與尺寸如 `RS-A4BK`、`20kg`、`4 米` 不受影響）。
